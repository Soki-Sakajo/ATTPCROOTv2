phase_space_6alpha.C：6つのアルファ粒子に崩壊
phase_space_hoyle.C ：12C(ground) + 12C(hoyle) に崩壊した後,12C(hoyle)が3つのアルファ粒子に崩壊

ROOTの動く環境で

と打てば走ります。

## プログラムの中心部分（イベント生成）について
/* event generator setting */ 以下で，「イベント生成のための変数の用意」，「何がどう崩壊するかの設定」を行っています．
* event がイベント生成のための変数です（C++の言葉で言えば，TGenPhaseSpaceというクラスのインスタンス）
* SetDecayメソッドで「4元ベクトルW（を持つ粒子）が nAlpha = 6個の粒子に崩壊する」という設定を行う（崩壊後の粒子質量もmasses配列で登録）

/* event generation (core part of this program) */ 以下のfor文内で実際にイベント生成（粒子崩壊）を行っています．
とりあえずは「doの行からwhileの行までが1セットで，ここで位相空間にしたがって粒子を崩壊させている」と理解しておけば十分です．
詳しくはTGenPhaseSpace::Generate()のソースコード（"TGenPhaseSpace source" などでググれば見つかります）を読んで欲しいのですが
* Generateメソッドは粒子崩壊を起こすが，これだけだと位相空間で一様にばらまいているわけではない
* その変わり，起こした崩壊イベントの「位相空間に従って崩壊したと思った時の，相対的な起こりやすさ(weight)」を返してくれる（絶対値に意味はない）
ということです．

ちなみに(0,weight_max)範囲の一様乱数 uniform_ran を使ってhit-or-miss法という単純な方法で，高いweightのイベントほど起こりやすくなるような処理をしています．
weight_maxの値はGenerate()が返す値(weight)の最大値より大きく設定しておけば正しく動くきます．
ただし大きくしすぎると，プログラムの実行速度が遅くなるので，通常ギリギリを攻めます．
Generate()が返す値の最大値はSetDecayで行った崩壊設定に依存するので，ここを変える場合にはweight_maxの値も変える必要があるかもしれません．


## その他瑣末な部分について
# 4元ベクトルを扱うTLorentzVectorというクラスを使っています．ググれば意味や使い方が出て来るので調べてみてください．
* beamという変数が入射粒子(12C)の4元運動量の情報を保持します
* targetという変数が標的粒子(12C)の4元運動量の情報を保持します
* Wという変数が系全体（今回のシミュレーションでは崩壊粒子の24Mgだと思ってもいいです）の4元運動量の情報を保持します

# Double_tやInt_tというROOT特有の型が使われていますが，doubleやintと同じと思っていいです．
doubleやintだと何バイトのメモリを確保するかが処理系依存（といってほとんどの処理系でdouble = 8 bytes, int = 4 bytesですが）なのに対し，Double_t, Int_t は確保するメモリの大きさがそれぞれ8, 4バイトであることを保証しています．

# ROOTでのヒストグラムの用意の仕方，Fillの仕方，描き方は読めば分かるように書いたつもりです．
ググれば色々な情報が得られます．（log表示，重ね書き，色を変える などのやり方も必要ならググってください）

# C/C++に関して
このプログラムを使うにあたって，C++のクラス（intやdoubleのような型みたいなものです．ただし少し機能が多い）という概念と，C/C++共通のポインタ変数（プログラム中で*付きで登場している変数のこと）という概念を知っていると便利です．これらをキーワードにして調べて見てください．ポインタに関してはプログラム中でメモリがどう使われるかを意識すれば理解しやすいです．
そのほかのキーワードとして，（このメールでもすでに使っていますが）
* メソッド（C++ではメンバ関数ということも多い） [クラス関連]
* インスタンス [クラス関連]
* new演算子 [ポインタ関連]
を挙げておきます．

# TGenPhaseSpaceのソースコードに関して（特にTGenPhaseSpace::Generate()）
読むととても物理の勉強になります．基本的には「ローレンツ不変な位相空間」に一様に分布するように粒子を崩壊させるためのコードです．もちろん運動学的に許された領域で．
僕が最初に読んだときはPDK関数の説明が無くてハマりました．（式はググればすぐ見つかりますが，知ってないと式だけ見ても何を表すか分からない）
PDK(a,b,c) : 質量aの粒子が重心系で質量b,cの粒子に2体崩壊するときの粒子bの運動量の大きさ（=粒子cの運動量の大きさ）です．
これさえ分かっていれば後は（頑張れば）問題なく読めるかなと思います．

* pAlpha[0], pAlpha[1], ..., pAlpha[5] : 崩壊後の6つのα粒子の4元運動量（TLorentzクラスの変数へのポインタになっています．）
* 上に関連して，「ドット演算子」「アロー演算子」というポインタ関連のキーワードを挙げます．
* 質量や運動エネルギーの値(M_alpha, M_12C, T_beam)は，書かれている値をあまり信用せず，適宜書き換えてください．
******************************************************************************

これに追加して,
*distという変数でターゲットと検出器の距離を設定
 TLorentzVectorの運動量からz=distの位置での(x,y)分布を計算しています。
*phase_space_hoyle.Cでは2回,イベント生成をさせています。
 TGenPhaseSpace event,event2 がそれぞれ1つめと2つめの崩壊のイベント生成のための変数です。
 event2.SetDecay(~)で1つめの崩壊でできた12C(hoyle)を次のイベントで崩壊する粒子に設定しています。
